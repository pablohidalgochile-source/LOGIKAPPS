Pack IA y Equipo

LOGIKAPPS 0.6.0 beta · 31 octubre 2026

FrateIA para preparar el Mac y una guía para colaborar con ChatGPT, GitHub y las herramientas del equipo.

  1. Descarga el pack y abre GUIA.html para preparar el Mac y tus cuentas.
  2. Instala FrateIA desde el ZIP incluido. Puedes explorar primero; los modelos se preparan en cada Mac.
  3. Solicita las invitaciones de ChatGPT, GitHub y FrateIA que correspondan. No se transfieren carpetas ni conversaciones locales automáticamente.
