# Herramientas disponibles en Explorar

LOGIKAPPS 0.3.0 muestra una selección pública desde el primer inicio. **Explorar** contiene las fichas; **Mis apps** contiene solo los accesos que cada persona agrega. Los paquetes se descargan por separado: no se instalan automáticamente ni se copian aplicaciones desde el equipo del creador.

## Surco · beta portable

[Descargar Surco 0.1.0 beta](https://github.com/pablohidalgochile-source/LOGIKAPPS/releases/download/v0.3.0-beta.1/Surco-0.1.0-beta.zip)

Biblioteca musical local, exploración de enlaces y grabación de audio de una pestaña. Esta entrega es código con un lanzador, **no una .app autónoma**. Requiere Python 3.10 o posterior y preparar las dependencias indicadas en [LEEME](../tools/surco/LEEME.md). Algunas funciones necesitan FFmpeg o Google Chrome.

Descomprime toda la carpeta, sigue LEEME y luego usa **Conectar lanzador** para seleccionar `Abrir Surco.command`. No selecciones el ZIP. La biblioteca se crea en el equipo de quien la usa; el paquete no contiene música ni una biblioteca previa.

La preparación de esta entrega comprueba el inicio local y la interfaz. No garantiza que cada plataforma externa permita descargar cualquier publicación. Sus requisitos y disponibilidad pueden cambiar.

## FRATV para OBS · pack de gráficas

[Descargar FRATV para OBS 0.1.0 beta](https://github.com/pablohidalgochile-source/LOGIKAPPS/releases/download/v0.3.0-beta.1/FRATV-OBS-Pack-0.1.0-beta.zip)

Incluye 15 recursos HTML con la identidad FRATV: rótulos, avisos, cuenta regresiva, programación, créditos y otras gráficas. Puedes previsualizarlos en un navegador de Mac, Windows o Linux. Para transmitir necesitas OBS Studio instalado por separado. No incluye el editor Overlay Studio.

Descomprime el ZIP y abre `fratv/GUIA-OBS.html`. Mantén juntas las carpetas `fratv` y `brand`. En LOGIKAPPS puedes usar **Conectar carpeta** para guardar un acceso a esa carpeta. Las piezas son horizontales a 1920 × 1080; una escena vertical necesita ajustes en OBS.

Los textos de ejemplo se pueden cambiar siguiendo `LEER-PRIMERO.txt`. Las tipografías usan Google Fonts por Internet; sin conexión se sustituyen por fuentes del sistema. [Guía oficial de fuentes de navegador en OBS](https://obsproject.com/kb/browser-source).

## FRATE Web

[Abrir FRATE Web](https://www.frate.cl/)

Sitio de Fraternidad Campus Central. Puedes guardarlo con **Agregar a Mis apps**. Es un sitio para mayores de 18 años y algunas funciones requieren una cuenta propia. La comprobación del catálogo verifica la página de entrada, no compras, cuentas ni operaciones internas. No incluye acceso a sistemas de administración.

## Actualizar desde la beta anterior

Instala LOGIKAPPS 0.3.0 y vuelve a abrirlo. Si tu biblioteca está vacía, se abrirá **Explorar**. Si ya tienes accesos, se conservarán y podrás entrar a Explorar desde la barra lateral. No hace falta borrar datos ni importar la biblioteca de otra persona.

El catálogo viene incluido en cada versión de LOGIKAPPS. Se actualiza al instalar una nueva versión; no consulta un servidor ni descarga herramientas en segundo plano. Las descargas públicas no contienen las bibliotecas personales del creador.
