# BINAURAL SYSTEM 0.1.0 · beta local

Esta es la aplicación independiente desarrollada el 8 de noviembre de 2026, con Estudio, Biblioteca, Programas, Sesiones, Meditaciones y Rituales.

1. Mantén esta carpeta completa fuera de Descargas temporales.
2. Instala Python 3 si no lo tienes y abre `Abrir BINAURAL SYSTEM.command`.
3. Se sirve exclusivamente en http://127.0.0.1:5194. Mantén Terminal abierto; Control+C termina el servidor. Si el puerto está ocupado, cierra la copia anterior; se conserva el puerto para no cambiar el almacenamiento.
4. En LOGIKAPPS pulsa Conectar lanzador y selecciona ese archivo .command.

No requiere cuenta ni claves para las funciones locales. La compilación incluida contiene sus dependencias; no descarga React, fuentes o Tailwind al abrir. Los datos se guardan en este navegador y origen; usa los respaldos de la app antes de cambiar de navegador o equipo. No importa datos de RESET DETOX automáticamente.

Incluye motor estéreo, programas, presets, historial, ambientes, audio propio y narración del sistema. La Forja usa plantillas locales; IA y voces remotas no están conectadas. El WAV contiene síntesis binaural, tono y ruido: no incluye ambientes, archivos personales ni narración. La escucha prolongada, pantalla bloqueada y todos los navegadores aún necesitan validación. Nombre/logo final pendientes.

El código fuente está incluido. Para desarrollo se requiere Node 22.12 o posterior: npm ci, npm test y npm run build. El lanzador usa la compilación de dist, no un servidor de desarrollo. Esta beta web local no incluye un DMG propio.
