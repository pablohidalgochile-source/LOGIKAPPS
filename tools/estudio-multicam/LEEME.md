# Estudio Multicam 1.0.0 · configuración pendiente

Mesa de realización, cámaras y salida de programa. Bullet Cam y retratos 3D son conceptos separados.

## Requisitos

Python 3, navegador con permisos de cámara/micrófono y servicios propios de señalización.

## Cómo abrir

Abre Abrir Estudio Multicam.command para revisar las pantallas. Antes de conectar cámaras, configura un proyecto Supabase propio en config.js. LiveKit/TURN y HTTPS para otros dispositivos requieren instalación y configuración adicionales.

## Estado y límites

Se retiró la conexión temporal a la infraestructura de Fraternidad del paquete público. No se activa una transmisión ni un servicio remoto al descargarlo. Conexión entre varios equipos pendiente de validar.

Las actualizaciones se descargan desde la release de LOGIKAPPS. Conserva tus datos antes de reemplazar una carpeta.
