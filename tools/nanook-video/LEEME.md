# INGESTA 3.0.4

Descarga, lotes y conversión MP4 desde enlaces públicos. El nombre anterior era NANOOK VIDEO.

## Requisitos

Node.js 22.13+, Python 3.10+, FFmpeg y ffprobe.

## Cómo abrir

Abre Preparar INGESTA.command una vez; luego Abrir INGESTA.command. La preparación descarga el extractor en esta carpeta. Instala FFmpeg/ffprobe por separado. Los archivos nuevos quedan en downloads.
