# Orgalina 0.2.0 · prototipo

Presupuesto doméstico, servicios y lectura de texto de boletas PDF.

## Requisitos

Node.js 22.13 o posterior y npm.

## Cómo abrir

Abre Preparar Orgalina.command una vez; después Abrir Orgalina.command. Tu base se crea vacía en data/orgalina.sqlite. Conserva esa carpeta al actualizar.

## Estado y límites

No procesa pagos reales ni sincroniza hogares por internet. Cada copia tiene sus datos locales. No incluye cuentas, boletas ni movimientos de otra persona.

Las actualizaciones se descargan desde la release de LOGIKAPPS. Conserva tus datos antes de reemplazar una carpeta.
