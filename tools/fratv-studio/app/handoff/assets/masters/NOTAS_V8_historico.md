# FRATV — firma tipográfica y bajada corregidas

- Las cinco letras de `FRATV` tienen el mismo tamaño, altura y línea base.
- `FRA` se mantiene en marfil.
- `TV` se mantiene en naranja y usa la misma tipografía redondeada.
- La bajada oficial es: **CONTENIDO DIGITAL HUMANO**.
- Se mantienen las alternativas 1 Equilibrado y 3 Diagonal para el TV interior del play.
