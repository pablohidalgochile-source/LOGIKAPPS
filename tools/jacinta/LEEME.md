# Jacinta M. Pastelería · versión local

Caja del día, pedidos de tortas y carta.

## Requisitos

Python 3 y navegador actualizado.

## Cómo abrir

Abre Abrir Jacinta.command. También puedes abrir index.html directamente. Configura tu clave y haz copias desde la app. Conserva la carpeta y el mismo navegador; los datos están en el almacenamiento del navegador.

## Estado y límites

Versión local sin numeración de producto explícita. No incluye pedidos ni cajas reales. El logo utilizado por el proyecto se conserva dentro de la app; no se trata como elección nueva para LOGIKAPPS.

Las actualizaciones se descargan desde la release de LOGIKAPPS. Conserva tus datos antes de reemplazar una carpeta.
