# TRACKHUNT portable 0.3

Actualizado desde el desarrollo del 5 de noviembre: navegación unificada, revisión de apariciones, Playlist Hunt, candidatos sin duplicados y enlaces Deezer. Conserva el almacenamiento SQLite local de esta distribución.

chrome-extension contiene la extensión propia para capturar fragmentos de una pestaña autorizada. mac-assistant contiene el asistente nativo y su motor ShazamIO: sigue su README y build-app.sh para compilarlo con las herramientas de Apple y su entorno Python. El pack no incorpora un binario del asistente ya preparado. La captura requiere tu clic en la extensión y no se activa al abrir LOGIKAPPS.

No incluye historial, música, cuentas ni claves. Las integraciones necesitan configuración propia. La identificación puede quedar incompleta; revisa versiones antes de exportar. No realiza descargas masivas de MP3/WAV.
