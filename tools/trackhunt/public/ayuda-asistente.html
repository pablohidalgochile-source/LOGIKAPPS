Asistente Mac y extensión Chrome

Esta edición portable incluye las fuentes del asistente 0.4.2. Su aplicación compilada no está incluida: necesitas prepararla antes de conectar reconocimiento acústico. El resto de TRACKHUNT puede utilizarse sin el asistente.

  1. En la carpeta del pack abre TRACKHUNT/mac-assistant/README.md.
  2. Necesitas un Mac Apple Silicon, herramientas Swift de Apple y Python compatible con engine/requirements.lock.
  3. Sigue los comandos de Build en ese README. El instalador del motor descarga dependencias; el reconocimiento usa ShazamIO, servicio no oficial.
  4. Abre la aplicación resultante y luego Sets → Conectar asistente.

Extensión Chrome 0.3.1

Sus archivos están en TRACKHUNT/chrome-extension dentro del pack. En Chrome abre chrome://extensions, activa Modo de desarrollador y elige Cargar descomprimida. Selecciona esa carpeta. Requiere el asistente funcionando; consulta su README para permisos e interrupciones.

No se incluyen historiales, grabaciones, sesiones ni cuentas del equipo de origen.
