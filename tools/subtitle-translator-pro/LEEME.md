# Subtitle Translator Pro 0.1.0 · en desarrollo

Edición y traducción de SRT/VTT conservando tiempos y formato.

## Requisitos

Node.js 22.13 o posterior y npm.

## Cómo abrir

Abre Preparar Subtitle Translator Pro.command; luego Abrir Subtitle Translator Pro.command. El proveedor y la clave se configuran por cada usuario en la interfaz según el modo elegido.

## Estado y límites

Compilación con comprobación TypeScript; no se hereda la configuración de lint de otros proyectos. Traducción externa no probada con una cuenta de colega. No incluye credenciales ni créditos de proveedores.

Las actualizaciones se descargan desde la release de LOGIKAPPS. Conserva tus datos antes de reemplazar una carpeta.
