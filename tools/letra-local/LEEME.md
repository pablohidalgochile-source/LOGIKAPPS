# Letra Local 0.3.0

Apple Silicon; macOS 14 o posterior recomendado. Descomprime Letra Local.zip en esta misma carpeta y conserva la app junto a transcribe.py. Instala Python 3.11+ y FFmpeg. Ejecuta Preparar Letra Local.command una vez: descarga dependencias y modelos (requiere internet y espacio libre). Después abre Letra Local.app y conéctala desde LOGIKAPPS.

Importa una canción; Separar la voz utiliza Demucs antes de Whisper. El audio se procesa localmente; la precisión puede variar. Para traducir, configura LM Studio con un modelo local y servidor en 127.0.0.1:1234. El dictado solicita permiso de micrófono y reconocimiento. No se incluyen canciones ni borradores. Firma ad-hoc, sin notarización. Si cambias de carpeta, mueve toda la carpeta Letra-Local, incluido el entorno preparado.
