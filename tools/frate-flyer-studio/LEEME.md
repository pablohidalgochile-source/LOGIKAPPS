# FRATE FLYER STUDIO 0.1.0 · prototipo

Editor y plantillas de flyers; proyecto distinto de Flyer Express.

## Requisitos

Python 3 y navegador actualizado para abrir el editor preparado.

## Cómo abrir

Abre Abrir FRATE FLYER STUDIO.command. La interfaz se entrega compilada sin cuentas configuradas. Consulta el código y package.json si necesitas continuar el desarrollo o configurar tu propio Supabase.

## Estado y límites

La bandeja conectada a Express y sus cuentas no están configuradas. Exportación automatizada requiere preparación del proyecto, Puppeteer y un navegador compatible; no se ha verificado aquí. No incluye datos o sesiones del equipo.

Las actualizaciones se descargan desde la release de LOGIKAPPS. Conserva tus datos antes de reemplazar una carpeta.
